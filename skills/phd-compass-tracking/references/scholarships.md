# External scholarship applications

For funding applied for separately from a position (government, foundation or home-country schemes). Scholarship entries live in the data block's `scholarships` list; details go under **Target notes** (chat) or `scholarships/<scheme>.md` (folder).

## For each scheme
1. **Terms, from the scheme's page:** what it covers (stipend, fees, travel, research costs), duration, the number of awards if stated.
2. **Eligibility against the owner's facts:** nationality and residence, degree level and timing, age or years-since-degree limits, field, host requirements (an accepted place, a supervisor's letter, a host from an approved list), return or service obligations. Set `eligible`: `yes`, `no` or `check`, with the open point named.
3. **Application:** documents, whether it needs a host agreement first (often the longest step), stages and dates, interview.
4. **Record:** `status` (`idea` → `checking` → `preparing` → `submitted` → `awarded` / `rejected`, or `not-eligible`), `deadline`, `link`, `note`. Add the steps with dates to `actions` when they are not tied to one target.

## Coordination
When a scheme needs a host agreement, link it to the relevant targets: note the scheme in each target's `notes`, and make getting the agreement the target's next action with a date well before the scheme's deadline.

Done when the scheme's eligibility is decided or its open point named, and every dated step is in the data block.
